它能做什么 What it does

把繁琐的批量改名变成「改一个、全自动」。

🧩

模板批量改名

第一个文件当作「改名模板」，你改一处，引擎按规律把同样的变换套用到所有文件。

🔢

标签自动编号

用 <n> 自动按 001、002… 补零编号，也能指定起始数字、引用父文件夹名。

🌐

纯网页零依赖

只有一个 HTML + 几个 JS 文件，断网也能用，可整页存到本地双击打开。

工作原理 How it works

不用学正则、不用写公式，靠「对齐」自动推理。

拖入文件

把文件夹拖进网页，或点「选择文件夹」。第一个文件会出现在模板框里。

改一个名字

把第一个文件名改成你想要的样子，比如加上前缀、编号或父目录名。

全部自动套用

引擎把「旧名→新名」的变换拆成片段做对齐，推断每个文件该怎么改，实时预览。

原始：01.mp4  →  你写：平屋慢生活.E01.mp4
引擎识别：在原始名 01 前面加了「平屋慢生活.E」、后面补了「.mp4」
套用到 02.mp4 → 平屋慢生活.E02.mp4，03 → 平屋慢生活.E03.mp4 ……以此类推。

标签速查（写进模板即可） Tags

标签就是「占位符」，软件会根据每个文件自动算出真正的内容。看不懂？直接点上面的「一键插入标签」。

标签写法大白话意思举个栗子（3 个文件）
<n>自动编号，位数跟着文件总数走（1→001，12→012）001、002、003
<n,5>自动编号，从第 5 个开始数005、006、007
<dir>放进当前文件夹的名字文件夹叫「照片」就填「照片」
<dir,2>向上数第 2 层父文件夹的名字如 D:\旅行\2024\照片 → 填「旅行」
<r>6 位随机数字（制造不重复的名字）如 482913
<r,4>4 位随机数字如 0193
<rl,4>4 位随机小写字母如 akzp
<ru,4>4 位随机大写字母如 AKZP
<ra,4>4 位随机小写字母 + 数字如 a3k9
<rA,4>4 位随机大写字母 + 数字如 A3K9
<rABC,4>4 位「ABC」里的随机组合（ABC 可换成任意字符）如 CBAABC
<abc>原样输出「abc」三个字。基本用不到：模板里直接打字本来就是原文；只有要原样输出像 <n> 这种「长得像标签」的文字时才需要输出 abc

小提示：模板里直接打字就是原文，比如写 假期照片_<n>，「假期照片_」会原样保留，只有 <n> 变成编号。归档到子文件夹：在模板里写 / 新建下级目录（如 Photos/<n>），../ 可上移一级。

常见问题 FAQ

要下载或安装吗？

不用。这是一个纯网页工具，打开就能用；也可以把整页存到本地双击打开。

我的文件会被上传吗？

不会。所有改名都在你自己的浏览器里完成，文件从不上传任何服务器。「选择文件夹」只会读取文件名来生成新名字。

为什么有的浏览器不能真实改名？

直接在本地改名需要 Chrome / Edge 等支持的「文件系统接口」；Safari / Firefox 暂不支持，建议访问在线版用 Chrome / Edge 操作。

双击打开 HTML 后拖不进去？

以 file:// 方式打开时浏览器禁止直接读取文件夹，建议访问在线版用 Chrome / Edge 操作。
