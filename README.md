# RenamerX

> 纯网页批量重命名工具：打开就能用，不下载、不安装，文件始终留在你的设备上。

RenamerX 是一个基于浏览器的批量文件重命名工具。把文件夹拖进页面，修改第一个文件名，其他文件会按照同样的变化自动生成预览；确认后才会真正修改本机文件。

它受到 SmanRenamer 的设计思路启发，但代码和实现均为独立作品。SmanRenamer 未公开源代码，本项目不包含其代码。

## 在线使用

- 中文版：<https://johnwish1590.github.io/renamerx/>
- English：<https://johnwish1590.github.io/renamerx/en/>
- 源代码：<https://github.com/JohnWish1590/renamerx>

页面会根据浏览器语言自动选择界面：所有 `zh-*` 语言（简体、繁体等）默认进入中文，其余语言默认进入英文。右上角可以随时切换 `中文 / EN`，选择会保存在当前浏览器中。

## 主要功能

- **批量重命名**：只编辑第一个文件名，其他文件自动跟随变化。
- **拖入即用**：整个网页都可以接收文件夹，不必精确拖到某个小区域。
- **实时预览**：原名称和新名称并排显示，新增、修改和删除的部分会高亮。
- **安全检查**：应用前检查重名、非法字符、未选中文件占用等问题。
- **选择性处理**：可以取消勾选某些文件，只重命名选中的文件。
- **子文件夹支持**：默认处理当前文件夹；勾选“包含子文件夹”后可以递归读取。
- **路径操作**：支持使用 `/` 归档到子文件夹，也支持使用 `../` 移动到上一级目录。
- **浅色、深色、跟随系统**：主题选择会保存在浏览器中。
- **中英文界面**：所有操作、状态、错误提示和兼容性说明都有对应英文版本。
- **本地优先**：文件内容不会上传；在线版只通过浏览器的文件权限访问用户主动选择的文件夹。

## 使用方法

1. 用最新版 Chrome 或 Edge 桌面版打开在线页面。
2. 把文件夹拖到网页任意位置，或点击“选择文件夹”。
3. 修改“把第一个文件名改成”输入框中的模板。
4. 查看预览，确认高亮变化和警告内容。
5. 点击“应用重命名”。完成后页面会显示成功提示和修改数量。

网页不需要安装客户端。文件夹被读取后，浏览器会显示文件权限确认；真正改名只会在用户点击确认按钮后发生。

## 模板标签

模板中的普通文字会原样保留，尖括号标签会根据文件和排序结果计算。

| 标签 | 作用 | 示例 |
| --- | --- | --- |
| `<n>` | 按选中文件顺序自动编号 | `Episode <n>` → `Episode 01` |
| `<n,5>` | 从指定数字开始编号 | `<n,5>` → `05`, `06`, `07` |
| `<dir>` / `<dir,1>` | 当前文件夹名称 | `Photos/<dir>` |
| `<dir,2>` | 向上第 2 层父文件夹名称 | `<dir,2>_<n>` |
| `<r>` / `<rn,4>` | 随机数字 | `<rn,4>` → `0427` |
| `<rl,4>` | 随机小写字母 | `akzp` |
| `<ru,4>` | 随机大写字母 | `AKZP` |
| `<ra,4>` / `<rA,4>` | 随机字母和数字 | `a3k9` / `A3K9` |
| `<rABC,6>` | 从自定义字符集随机取值 | `CBAABC` |

`/` 或 `\` 可以把文件移入子文件夹，例如 `Photos/<n>`；`../` 或 `..\` 可以把文件移动到上一级目录。

## 浏览器兼容性

在线版在 Chrome 和 Edge 桌面版中支持直接修改本机文件，需要浏览器支持 File System Access API。

Safari、Firefox、`file://` 直接打开 HTML 等环境可以使用兼容模式读取文件名并预览，但不能直接写回本机文件。需要真正改名时，请使用在线版或本地启动一个 HTTP 服务。

## 本地开发

```bash
git clone https://github.com/JohnWish1590/renamerx.git
cd renamerx
npm install
node server.mjs
```

然后打开 <http://localhost:5173/>。英文页面地址是 <http://localhost:5173/en/>。

运行测试：

```bash
npm test
node --check app.js
```

测试覆盖重命名算法、标签求值、路径解析、冲突检测、PowerShell 脚本生成兼容性、API 和页面交互。

## 统计与隐私

页面底部展示累计服务用户数和累计改名文件数。统计接口位于服务端，按 IP 做哈希后限流，不在前端保存密钥，也不保存明文 IP。文件名和文件内容不会上传到统计服务。
