📖 标签语法与使用原理

核心原理

拖入一批结构相似的文件后，列表中排在第一位的文件名会成为「重命名模板」。 你只修改这个模板名，软件会通过单词对齐把你的改动套用到所有文件：

  • 把 Plan Report 2023 改成 P R 2023 → 其他文件自动取每个单词的首字母。
  • 删掉某个词、在某处插入文字、调整大小写，都会按相同规则应用到每个文件。

⚠️ 软件可能无法完全理解你的改名意图，重命名前请务必核对每个文件名！

标签（可直接写进模板）

<n>自动编号，按文件总数自动补零（001、002…）
<n,x>自动编号，从第 x 个开始
<dir> / <dir,1>所在文件夹名
<dir,x>向上 x 级的父文件夹名
<r>6 位随机数字
<r,x> / <rn,x>x 位随机数字
<rl,x>x 位随机小写字母
<ru,x>x 位随机大写字母
<ra,x>x 位随机小写字母+数字
<rA,x>x 位随机大写字母+数字
<rABC,x>x 位自定义字符（ABC 可换成任意字符）
<abc>原样输出文字 abc（用 <> 包裹可强制固定文本，不随各文件变化）

归档到子文件夹

在模板里用 / 或 \ 新建下级目录，例如 Photos/<n> 会把文件移入 Photos 子目录； 用 ../ 或 ..\ 可把文件上移一级。
