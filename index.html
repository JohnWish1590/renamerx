📖 标签说明与使用原理（看不懂语法？点这里）

核心原理

拖入一批结构相似的文件后，列表中排在第一位的文件名会成为「重命名模板」。 你只修改这个模板名，软件会通过单词对齐把你的改动套用到所有文件：

  • 把 Plan Report 2023 改成 P R 2023 → 其他文件自动取每个单词的首字母。
  • 删掉某个词、在某处插入文字、调整大小写，都会按相同规则应用到每个文件。

⚠️ 软件可能无法完全理解你的改名意图，重命名前请务必核对每个文件名！

标签说明（可直接写进模板，不用背，上面有「一键插入」）

标签就是「占位符」，软件会根据每个文件自动算出真正的内容。大白话解释如下：

标签写法大白话意思举个栗子（3 个文件）
<n>自动编号，位数跟着文件总数走（1→001，12→012）001、002、003
<n,5>自动编号，从第 5 个开始数005、006、007
<dir>放进当前文件夹的名字文件夹叫「照片」就填「照片」
<dir,2>向上数第 2 层父文件夹的名字如 D:\旅行\2024\照片 → 填「旅行」
<r>6 位随机数字（制造不重复的名字）如 482913
<r,4>4 位随机数字如 0193
<rl,4>4 位随机小写字母如 akzp
<ru,4>4 位随机大写字母如 AKZP
<ra,4>4 位随机小写字母 + 数字如 a3k9
<rA,4>4 位随机大写字母 + 数字如 A3K9
<rABC,4>4 位「ABC」里的随机组合（ABC 可换成任意字符）如 CBAABC
<abc>原样输出「abc」三个字。基本用不到：模板里直接打字本来就是原文；只有要原样输出像 <n> 这种「长得像标签」的文字时才需要输出 abc

小提示：模板里直接打字就是原文，比如写 假期照片_<n>，「假期照片_」会原样保留，只有 <n> 变成编号。

归档到子文件夹

在模板里用 / 或 \ 新建下级目录，例如 Photos/<n> 会把文件移入 Photos 子目录； 用 ../ 或 ..\ 可把文件上移一级。
